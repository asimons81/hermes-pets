# Hermes Pets v0.6.0 Release Candidate

Date: 2026-05-24

## Verdict

v0.6.0 is the Hermes Pets shareability release candidate.

The release is locally prepared and may be pushed/tagged/released only after Tony explicitly approves the public release operation.

Do not publish to PyPI, build an installer, add a hosted gallery, add accounts, add public posting from inside the app, expand native platform support, or redesign the dashboard as part of v0.6.0.

## Release thesis

Turn a real local work session into a sharp, shareable recap card with receipts.

```text
Local pet activity -> recap card renderer -> local export bundle -> manual handoff
```

## Scope completed

- Built a deterministic static recap card renderer.
- Built a local export bundle containing `recap-card.png`, `caption.txt`, and `metadata.json`.
- Added a narrow CLI entry point for recap export.
- Added deterministic tests for the renderer and export flow.
- Reviewed the merged result end to end and fixed the final visual polish gap before signoff.
