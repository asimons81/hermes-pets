# Hermes Pets v0.5.0 Release Record

Date: 2026-05-20

## Verdict

v0.5.0 shipped as the Codex custom-pet trust release.

PyPI, installer publishing, hosted dashboard/gallery support, drag/drop import, native platform expansion, full voice mode, rich achievements, and dashboard redesign stayed out of scope for v0.5.0.

## Release thesis

Prove the complete operator path:

```text
Find or generate a Codex pet -> discover it -> import it -> activate it -> preview it -> render it in the live WSL/Windows overlay
```

## Scope completed

- Real Codex desktop pet fixtures were discovered in local WSL and Windows Codex stores.
- The editable uv-tool runtime was repaired and verified with Pillow present.
- CLI Codex discovery now labels duplicate WSL/Windows sources.
- CLI and dashboard Codex import can use explicit direct paths when duplicate slugs exist.
- Dashboard Import From Codex was verified across empty, populated, latest, direct path, custom install name, duplicate, replace, use-after-import, bridge-offline, and selected-sprite states.
- Live WSL/Windows overlay verification passed with a real Codex-imported pet.
- Package metadata and lockfile were bumped to `0.5.0` for the release.
