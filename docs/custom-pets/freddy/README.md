# Freddy

Freddy is a curated Hermes Pets custom pet package imported from user-owned Codex pet assets and prepared for repository distribution.

## Included states

- `failed`
- `idle`
- `jumping`
- `review`
- `run_left`
- `run_right`
- `running`
- `waiting`
- `waving`

## Validation

```bash
hermes-pet custom-pet validate docs/custom-pets/freddy
hermes-pet custom-pet preview docs/custom-pets/freddy --output /tmp/freddy-preview.html
```
