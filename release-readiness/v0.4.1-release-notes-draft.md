# Archived Hermes Pets v0.4.1 Release Notes Draft

Historical corrective patch release draft for the public v0.4.0 trust/update release.

## Summary

v0.4.1 fixes release hygiene and WSL/Windows launch reliability problems found after v0.4.0 was published. It does not add a new product feature track, publish to PyPI, ship a Windows installer, or change the supported platform matrix.

## Fixed

- Bumped the package to `0.4.1` and regenerated `uv.lock` so package metadata and lockfile version surfaces agree.
- Improved `hermes-pet update` install diagnostics so an inherited `VIRTUAL_ENV` mismatch is reported instead of masking the Python executable's actual virtual environment.
- Hardened the Windows overlay launcher:
  - stops existing Electron process trees with bounded retry;
  - recognizes stale Electron subprocesses from the Hermes Pets Electron cache;
  - mirrors the overlay app into `%LOCALAPPDATA%\HermesAgent\pet-overlay-electron\app-<port>` before launch so Electron reads renderer files from a native Windows path instead of a WSL UNC path.
- Hardened `scripts/verify-live-overlay.sh` with bounded retry for transient Windows/Electron startup and teardown races.
- Refreshed README, current-state notes, changelog, and release-readiness records for the corrective release.

## Validation to cite only if final report confirms

Historical note: this validation checklist applied to the v0.4.1 recovery draft and should not be used as current release guidance.

- `uv run pytest tests/test_update_command.py -q`
- `node --check overlay/src/main.windows.js`
- `node --check src/hermes_pet/overlay/src/main.windows.js`
- PowerShell syntax check for both root and packaged Windows launchers
- `PYTHON=.venv/bin/python scripts/verify-live-overlay.sh`
- Dirty/restarted overlay verifier scenario
- Full release validation stack and fresh local install smoke

## Explicit non-claims

- No PyPI publication.
- No Windows installer.
- No hosted dashboard or hosted custom-pet gallery.
- Native Linux, macOS, and native Windows remain investigation targets only for full overlay support.
