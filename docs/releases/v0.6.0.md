# Hermes Pets v0.6.0 Shareability Release

Date: 2026-05-24

## Verdict

v0.6.0 shipped as the Hermes Pets shareability release build.

PyPI, installer publishing, hosted sharing, accounts, public posting from inside the app, native platform expansion, and dashboard redesign stayed out of scope for v0.6.0.

## Release thesis

Turn a real local work session into a sharp, shareable recap card with receipts.

```text
Local pet activity -> recap card renderer -> local export bundle -> manual handoff
```

## Scope completed

- Built a deterministic static recap card renderer.
- Built a local export bundle containing `recap-card.png`, `caption.txt`, and `metadata.json`.
- Added a narrow CLI entry point for recap export.
- Added deterministic tests for the renderer and export flow.
- Reviewed the merged result end to end and fixed the final visual polish gap before signoff.
- Bumped package metadata and lockfile version surfaces to `0.6.0`.
- Kept the release local-first, with manual handoff instead of hosted sharing or public posting from inside the app.

The shipped release was validated with:

## Release boundary

Local build/test/verification were completed before the release was cut.

Public release operations were handled separately, and PyPI upload, installer artifacts, and public announcement stayed out of scope.
