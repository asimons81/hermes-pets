# Hermes Pets v0.5.0 Release Candidate

Date: 2026-05-20

## Verdict

v0.5.0 is the Codex custom-pet trust release candidate.

The release is locally prepared and may be pushed/tagged/released only after Tony explicitly approves the public release operation.

Do not publish to PyPI, build an installer, claim hosted dashboard/gallery support, add drag/drop import, expand native platform support, ship full voice mode, add rich achievements, or redesign the dashboard as part of v0.5.0.

## Release thesis

Prove the complete operator path:

```text
Find/generate Codex pet -> discover it -> import it -> activate it -> preview it -> render it in the live WSL/Windows overlay
```
