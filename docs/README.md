## How to use this map

- Start with the current docs if you want to know what Hermes Pets does right now.
- Open the operational docs if you want to run, verify, or ship the thing.
- Use the release and historical docs only when you need evidence, context, or a past cleanup trail.

If this map ever feels stale, fix the map first. Then move the doc in question into the right bucket instead of leaving it in the wrong one.
