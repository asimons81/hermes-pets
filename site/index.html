What it does

It turns local Hermes activity into a visible companion layer.

The overlay is transparent, always on top, draggable, and fed by a local WebSocket bridge. Sprite manifests define frame counts, frame rates, looping, and fallback behavior, so idle, hover, drag, run, review, jump, fail, and bubble states stay deterministic.

01

Transparent Electron overlay

Frameless, transparent, and always on top. It sits on the desktop without pretending to be a dashboard.

02

Python WebSocket bridge

The overlay listens to a local bridge and reconnects cleanly when the socket blips. No cloud hop.

03

Manifested sprite states

Sprite packs declare fps, loop behavior, and fallback state rules for idle, drag, hover, and message reactions.

04

Custom pet packs

Packages live under ${HERMES_PET_HOME:-~/.hermes_pet}/custom-pets/<pet-name>/ and can be validated before use.

05

Guarded update flow

update --check and --dry-run let you see the move before anything mutates the tree.

06

Local dashboard and diagnostics

doctor, overlay-status, and the localhost dashboard keep the operator loop honest.

Reality check

Local-first means local-first.

No hosted gallery. No remote upload flow. No cloud account. The repo also says native Linux, macOS, and native Windows overlay support are still investigation targets, while WSL2 on Windows is the supported full experience.

Local state

Pet data lives under ~/.hermes_pet by default, with HERMES_PET_HOME for isolation.

Private dashboard

The operator console binds to localhost only and uses a per-process token. It is not a hosted surface.

Public install path

The supported public install flow in the repo is GitHub-based, not a PyPI or installer release.

Operator install and use

Verified commands only, no made-up workflow garnish.

The repo supports local editable installs, a GitHub install path, the launch bridge, custom pet validation, and the guarded update flow.

User install 
python3 -m pip install 'git+https://github.com/asimons81/hermes-pets.git'
hermes-pet launch
hermes-pet doctor

What this is for

The public install path from the repo, then the local launch and diagnostics commands you actually run.

Operator note

The overlay is local and stateful, so if the bridge is already up, launch reuses the live path instead of pretending to be stateless theater.

Developer workflow 
cd <repo>
pip install -e .
hermes-pet custom-pet validate docs/custom-pets/freddy
hermes-pet update --check

What this is for

Editable local development, custom pet validation, and the guarded update flow before you touch anything on disk.

Scope

Use this when you’re working on the repo itself, not when you just want to launch the companion.
